How the SVG to PNG conversion works

1

Vector in

You drop an .svg file. The markup is read and loaded as an image object inside your own browser tab — no file is posted anywhere, and nothing is queued for a worker.

2

Rasterized at your pixel size

The vector is redrawn onto a canvas at the exact width and height you typed (up to 8000 px). This is the one irreversible step in the whole process: PNG does not scale back up, so choose the final size before you convert.

3

RGBA PNG out

The canvas is encoded as a lossless RGBA PNG. Transparency survives, edges stay crisp, and there is no re-compression generation loss however many times you convert the same asset.

FAQ

Should I convert at 1x or 2x my display size?

Export at 2x the CSS size you will render the image at: a 24 px icon becomes a 48 x 48 px PNG. PNG scales down cleanly in a browser, but it never scales up without blur, so the largest size you are likely to need is the size to convert at.

Will the transparent background survive the conversion?

Yes. The output is RGBA PNG, so transparency defined in the SVG stays transparent. A white box only appears if the SVG itself paints one.

Why is there a white box behind my icon?

Usually the SVG paints a full-size white rectangle, sets a CSS background, or relies on a font the browser has to substitute. Open the file in a text editor, look for a shape that covers the whole viewBox, remove it and convert again.

Do web fonts and text labels convert correctly?

Only when the font is web-safe or embedded in the file. If the SVG merely references a system font, the rasterizer substitutes whatever is installed on your machine, so convert text to outlines in your editor when the exact typeface matters.

Does the quality setting shrink the PNG file?

PNG is a lossless format, so a quality factor does not reduce its size the way it does for JPEG. To lose real bytes, convert at a smaller pixel size, or convert the image to WebP instead.

Is there a file size or conversion limit?

No. Nothing is uploaded and there is no account or quota, so the only ceiling is your device memory. Very large drawings, heavy filters or hundreds of paths simply take longer to rasterize.
